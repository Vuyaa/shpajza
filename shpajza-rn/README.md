# Shpajza React Native

A simple Expo-based mobile app for login, inventory management, settings, and recipe suggestions.

## Quick start

```bash
npm install
npm start
```

Then run on your device or emulator:

- Android: `npm run android`
- iOS: `npm run ios`

## Included features

- Login screen
- Inventory screen with add/remove items
- Settings screen
- Recipe suggestion based on current inventory
- Local persistence with AsyncStorage

## Structure

- `App.tsx`
- `src/navigation/AppNavigator.tsx`
- `src/screens/*.tsx`
- `src/services/api.ts`
